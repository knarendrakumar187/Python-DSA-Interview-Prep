# Python for DSA Course

## How to learn (important)
1. Open topics **in order** (01 → 33)
2. Read + type every example yourself
3. Do practice problems + mini quiz
4. In chat with mentor: finish one topic, then say **`Next`**
5. Don’t jump ahead
