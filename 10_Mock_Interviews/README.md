# Mock Interviews — How to use

## Rules
1. Put phone timer on
2. No peeping solutions
3. Speak your approach out loud (even alone)
4. After finish: mark PASS/FAIL in PROGRESS.md
5. Re-solve FAIL within 48 hours

## Files
- `mixed_day12.py` — mixed patterns (untimed first, then timed)
- `mock1_timed.py` — 3 problems, 70 minutes
- `FULL_MOCK_SCRIPT.md` — full interview script (DSA + resume + CS + HR)
