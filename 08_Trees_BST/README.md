# Trees & BST — Simple Notes

## Tree in one line
A structure with a **root**, and each node can have left/right child.

```
      1
     / \
    2   3
   /
  4
```

## Traversals (must say names)
- **Inorder:** Left → Root → Right
- **Preorder:** Root → Left → Right
- **Postorder:** Left → Right → Root
- **Level order:** level by level (BFS with queue)

## BST (Binary Search Tree)
Left < Root < Right  
Search is like binary search.

## Must-know problems
1. Max depth
2. Same tree
3. Invert tree
4. Traversals

For tree questions, first ask: "Can I use recursion?" Usually yes.
