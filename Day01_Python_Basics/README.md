## Must-know structures
| Tool | Use |
|------|-----|
| `list` | ordered values |
| `dict` | key → value (hash map) |
| `set` | unique values, fast check |
| `str` | text (immutable) |

## Complexity (memorize)
- dict/set average lookup: **O(1)**
- list scan/search: **O(n)**
- sorting: **O(n log n)**
