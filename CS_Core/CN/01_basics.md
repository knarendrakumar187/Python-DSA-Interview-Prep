# CN 01 — Basics, OSI, HTTP, DNS

## Why networks?
Devices share data. Internet = many networks connected.

## LAN / MAN / WAN
- LAN: home/college
- WAN: across cities/countries (internet scale)

## OSI 7 layers (remember order)
**P**lease **D**o **N**ot **T**hrow **S**ausage **P**izza **A**way  
Physical → Data Link → Network → Transport → Session → Presentation → Application

Interview: don’t only recite. Know where things sit:
- **HTTP/DNS/FTP** → Application
- **TCP/UDP** → Transport
- **IP** → Network
- **MAC** → Data Link

## TCP/IP model (4 layers)
Network Access → Internet → Transport → Application

## HTTP vs HTTPS
HTTPS = HTTP + TLS encryption. Safer for passwords/payments.

## DNS
Converts `google.com` → IP address.

## Speak answer
> OSI helps us understand network functions layer by layer. HTTP is application protocol; TCP provides reliable transport; DNS maps domain names to IPs. HTTPS encrypts HTTP with TLS.
